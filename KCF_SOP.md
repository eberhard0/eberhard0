## Catatan Perubahan SOP

- **Sales** hanya menangani proses dari proposing / pengiriman quotation hingga deal / penandatanganan paket

## Alur Lengkap KCF

### 1. Pre Sales

1. **SI / TPD / PIC KCF** mengirimkan brief ke **SM Planner**
2. **SM Planner** menyusun Proposal / Paket
   - SM berkordinasi dengan PIC KCF / TPD jika ada tambahan budget / konsep / dll
3. **SI / TPD / PIC KCF** melakukan Present Proposal ke klien
   - Jika ada **revisi**: kirim brief revisi kembali ke SM Planner → ulangi langkah 1-3
   - Jika **DEAL**: lanjut ke langkah berikutnya

### 2. Sales (Quotation & Deal)

4. **Mbak Ayu** request quotation
5. Koordinasi dengan **SM (Mas Andre)** untuk menyiapkan quotation
6. Quotation dikirim ke klien
7. **(!) Follow up status penandatanganan quotation** - pastikan konfirmasi apakah sudah ditandatangani atau belum
8. Setelah deal dikonfirmasi, **Marketing Support** menerima request Memo dari Sales berdasarkan Proposal / paket deal

### 3. Post Sales (berjalan paralel setelah deal)

| # | Aktivitas | PIC |
|---|-----------|-----|
| A | Tarik data revenue | Data Analyst |
| B | TPD melakukan pengaktifan akun | TPD |
| C | Membuat Invoice dan melakukan penagihan | Finance (AR) |
| D | Input data ke Fastcom dan membuat nomor SO | ACS (Sales Support KMN) |
| E | Kirim Memo (SPK) ke Sales Support, Sales, Finance, dan PIC produk terkait | Marketing Support |
| F | Pembuatan DiPK berdasarkan RAB dan proyeksi revenue | Admin KCF |
| G | Check kesesuaian budget; jika Approved → Dana Cair | Finance |
| H | Approve budget berdasarkan memo | Finance |
| I | Mengeluarkan kontraprestasi berdasarkan paket Approved | PIC KCF |

### 4. Invoice & Pembayaran

9. Setelah quotation ditandatangani klien, minta **invoice** dan **faktur pajak** ke Finance (Mas Jarwo)
10. Invoice dan faktur pajak dikirim ke klien

### 5. Kegiatan / Event KCF

11. Buat **RAB** (Rencana Anggaran Biaya) untuk kegiatan KCF
12. Buat request **pembayaran honorarium**, ditandatangani oleh **Mas APO** dan **Mas Maryoto**
13. Buat **memo pembayaran** yang ditujukan ke Finance untuk kegiatan KCF
14. Buat **surat-surat** lain yang diperlukan
