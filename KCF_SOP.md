## Workflow KCF

### PRE SALES

1. **SI / TPD / PIC KCF** mengirimkan brief ke **SM Planner**
2. **SM Planner** menyusun Proposal / Paket
   - SM berkordinasi dengan PIC KCF / TPD jika ada tambahan budget / konsep / dll
3. **SI / TPD / PIC KCF** melakukan Present Proposal ke klien
   - Jika ada revisi: kirim brief revisi kembali ke SM Planner (ulangi langkah 2-3)
   - Jika **DEAL**: konfirmasi deal

### SALES

4. Setelah deal, **Marketing Support** menerima request Memo dari Sales berdasarkan Proposal / paket deal

### POST SALES (berjalan paralel)

| # | Aktivitas | PIC |
|---|-----------|-----|
| A | Tarik data revenue | **Data Analyst** |
| B | TPD melakukan pengaktifan akun (paralel dengan Data Analyst) | **TPD** |
| C | Membuat Invoice dan melakukan penagihan | **Finance (AR)** |
| D | Input data ke Fastcom dan membuat nomor SO | **ACS (Sales Support KMN)** |
| E | Kirim Memo (SPK) ke Sales Support, Sales, Finance, dan PIC produk terkait | **Marketing Support** |

## Alur Detail (Konteks Handover)

1. **Mbak Ayu** request quotation
2. Koordinasi dengan **SM (Mas Andre)** untuk menyiapkan quotation
3. Quotation dikirim ke klien
4. Setelah quotation ditandatangani klien:
   - **(!) Perlu di-follow up status penandatanganan quotation**
   - Minta **invoice** dan **faktur pajak** ke Finance (Mas Jarwo)
5. Invoice dan faktur pajak dikirim ke klien
6. Apabila ada **acara KCF**:
   - Buat request pembayaran honorarium
   - Ditandatangani oleh **Mas APO** dan **Mas Maryoto**
7. Buat **memo pembayaran** yang ditujukan ke Finance untuk kegiatan KCF
